# Нота

Тренажёр чтения нот и поиска нот на гитаре. Интерфейс адаптирован для телефона: крупные кнопки, короткие тренировки и спокойная обратная связь.

С ❤️ от Yunki для Kaada.

## Диапазон

- Стандартный строй шестиструнной гитары.
- Открытые струны и первые три лада.
- От **Ми открытой шестой струны** до **Соль на третьем ладу первой струны**.
- **17 разных высот**, только ноты без диезов и бемолей.
- Названия на русском с буквенным обозначением: **До (C)**, **Ре (D)** и так далее.

Используется гитарная запись в скрипичном ключе: ноты записаны на октаву выше звучания. Звучащий диапазон — E2–G4, записанный — E3–G5.

## Режимы

| Режим | Задание | Ответ |
| --- | --- | --- |
| **Узнай ноту** | Нота на стане | Выбрать название |
| **Нота → гриф** | Нота на стане | Нажать нужную струну и лад |
| **Гриф → нота** | Отмеченное место на грифе | Выбрать соответствующую ноту на стане из четырёх вариантов |
| **С гитарой** | Нота на стане | Сыграть её на настоящей гитаре через микрофон |

На нарисованном грифе первая, самая тонкая струна находится сверху, шестая — снизу. Столбец **0** означает открытую струну.

В режиме «Узнай ноту» проверяется название. В остальных режимах важна точная высота, включая октаву.

## Как проходит тренировка

1. Выберите режим и нажмите **«Начать тренировку»**.
2. Выполните 10 заданий. Варианты ответов перемешиваются.
3. При верном ответе сразу появляется следующая нота. Короткое сообщение об успехе исчезает через 1,5 секунды.
4. После ошибки в режимах с кнопками можно прочитать объяснение и самостоятельно перейти дальше.
5. В конце отображаются результат и время ответов.

Ноты, вызвавшие трудности, встречаются чаще. Одна и та же высота не повторяется подряд.

Смена режима начинает новую тренировку. Уже записанные ответы сохраняются, а статистика каждого режима ведётся отдельно.

## Игра через микрофон

Режим рассчитан на одиночные ноты акустической гитары и встроенный микрофон телефона.

1. Откройте режим **«С гитарой»** и начните тренировку.
2. Нажмите **«Включить микрофон»** и разрешите доступ в браузере.
3. Приглушите струны и дождитесь сообщения **«Слушаю…»**.
4. Сыграйте одну ноту, приглушая остальные струны.

### Обратная связь

- Индикатор уровня показывает, что микрофон слышит звук.
- Если звук не удаётся уверенно определить, появится просьба сыграть одну струну.
- Неверно распознанная нота выделяется **оранжевым**. Можно продолжать искать нужную струну и лад — задание не завершается.
- Верная нота выделяется **зелёным**. При включённом звуке звучит короткое уведомление.
- После перехода к следующему заданию появляется **«Приглуши струну»**. Проверка и скрытый таймер ждут затухания предыдущего звука.

Ожидание затухания требует минимум 300 мс тишины ниже порога чувствительности. Это ожидание не считается ошибкой или перерывом для рекорда.

Статистика **«без поиска»** показывает, сколько заданий выполнено без предварительного распознавания другой ноты. Каждый неверный звук не создаёт отдельную ошибку в статистике.

### Доступ и приватность

- На телефоне нужен **HTTPS с доверенным сертификатом**.
- Обычный адрес Vite вида `http://192.168…` не даёт доступ к микрофону на телефоне.
- Для разработки на компьютере подходит `http://localhost`.
- При отказе в доступе разрешите микрофон в настройках сайта Chrome или Safari.
- Звук анализируется на устройстве: аудиозапись не создаётся и не отправляется на сервер.
- Микрофон выключается при смене режима, завершении тренировки и скрытии вкладки. После возвращения его нужно включить снова.

Синтез нот в микрофонном режиме отключён. Короткий сигнал успеха воспроизводится с учётом настройки громкости; во время сигнала распознавание заблокировано.

Распознавание проверено на синтетических сигналах. Точность на реальной гитаре зависит от микрофона, фонового шума и настройки инструмента; проверка на конкретном телефоне остаётся необходимой.

## Подсказки и шпаргалка

В задании доступна подсказка с названием ноты, её расположением на стане, струной и ладом.

Раскрывающаяся **«Шпаргалка»** содержит все ноты диапазона с пояснениями. В режимах с грифом и микрофоном также есть подписанный гриф: выберите ноту, чтобы увидеть её запись на стане. В режимах без микрофона её можно послушать.

Если открыть подсказку или шпаргалку во время задания, ответ учитывается как ответ с помощью, даже после закрытия подсказки. В микрофонном режиме распознавание приостанавливается, пока подсказка или шпаргалка открыта.

## Прогресс и рекорды

Блок **«Мой прогресс»** по умолчанию свёрнут. Для каждой ноты доступны:

- полоса освоения;
- число самостоятельных верных ответов и попыток;
- число ответов с подсказкой;
- среднее время последних 10 верных самостоятельных ответов без перерывов;
- положение на грифе.

Статус определяется по последним 10 самостоятельным попыткам:

| Условие | Статус |
| --- | --- |
| Нет попыток | Ещё не пробовали |
| Меньше 5 самостоятельных попыток | Мало данных |
| От 80% верных ответов | Помню хорошо |
| От 50% до 79% | Закрепляю |
| Ниже 50% | Стоит повторить |

Таймер работает **скрыто**: перед началом и во время задания отсчёт не отображается. Общее и среднее время видны в итогах. Время разбора ошибки и ожидания затухания струны не учитывается.

Рекорд сохраняется отдельно для каждого режима за **10 верных самостоятельных ответов без подсказок и перерывов**. В режиме с микрофоном также не должно быть предварительно распознанных неверных нот.

Кнопка **«Сбросить прогресс режима»** требует подтверждения и удаляет статистику и рекорды только выбранного режима. Настройки звука и результаты других режимов сохраняются.

## Звук

При первом открытии можно выбрать занятия со звуком или без него. Кнопка **«Выбрать звук»** повторно открывает это окно.

В шапке доступны выключатель звука и ползунок громкости. Настройки сохраняются между посещениями.

Звучание нот синтезируется через Web Audio и имитирует щипок гитарной струны: короткая атака, обертоны и постепенное затухание. Это синтез, а не запись настоящей гитары.

## Локальный запуск

Используйте **Node.js 24** и npm.

```sh
npm ci
npm run dev
```

Если PowerShell блокирует запуск `npm.ps1`, используйте `npm.cmd` вместо `npm`.

Для обычных режимов на телефоне в той же Wi-Fi сети откройте **Network URL**, который выводит Vite. При необходимости разрешите Node.js доступ к частной сети в брандмауэре.

Для режима с микрофоном на телефоне потребуется HTTPS, как описано выше.

## Сборка и размещение

```sh
npm run build
npm run preview
```

Команда сборки проверяет TypeScript и создаёт папку `dist`. Её содержимое можно разместить на статическом хостинге с HTTPS. Серверная часть не требуется.

`npm run preview` предназначен для локальной проверки сборки и сам по себе не включает HTTPS.

## GitHub Pages

Автоматическая публикация настроена в `.github/workflows/pages.yml`.

1. В репозитории `brownyunki/NOTA` откройте **Settings → Pages**.
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
3. Отправьте изменения в ветку `main`.
4. Во вкладке **Actions** дождитесь успешного выполнения **Deploy GitHub Pages**.
5. Откройте **https://brownyunki.github.io/NOTA/**.

Workflow устанавливает зависимости, запускает тесты и собирает приложение с базовым путём `/NOTA/`. Локальный запуск по-прежнему работает от корня сайта. При следующих push в `main` сайт обновляется автоматически. Папку `dist` коммитить не нужно.

Для ручного запуска используйте **Actions → Deploy GitHub Pages → Run workflow**. HTTPS-адрес Pages подходит для запроса микрофона на телефоне.

## Тесты


```sh
node --test src/progress.test.mjs src/training.test.mjs src/timing.test.mjs src/pitch.test.mjs src/silence-gate.test.mjs
```

Тесты проверяют:

- сохранение и перенос прогресса;
- соответствие нот струнам и ладам;
- выбор заданий и вариантов ответа;
- расчёт времени и рекордов;
- распознавание высоты, октав и тишины;
- ожидание затухания струны перед следующим заданием.

## Технологии и хранение данных

- React 19.
- TypeScript в строгом режиме.
- Vite.
- Web Audio API и `getUserMedia`.
- `localStorage` для прогресса и настроек.

Регистрация не нужна. Данные остаются в текущем браузере и не синхронизируются между устройствами. Очистка данных сайта удалит сохранённые результаты.
