# Нота

## Режим «С гитарой»

Одиночные ноты акустической гитары через микрофон телефона. После старта нажмите «Включить микрофон» и разрешите доступ. На экране только заданная нота; струна и лад доступны в подсказке. Индикатор показывает входящий звук, подпись — распознанную ноту или неуверенное распознавание. Неверные звуки не завершают задание. После устойчивого совпадения высоты (октава учитывается) выполняется автоматический переход. Статистика «без поиска» показывает задания, решённые без предварительного распознавания других нот; за каждый неверный звук отдельного штрафа нет. Подсказки учитываются отдельно. Записи не создаются и не отправляются, анализ выполняется локально. Микрофон останавливается при смене режима, завершении тренировки и скрытии вкладки. Синтезированный звук в этом режиме отключён.

На телефоне нужен HTTPS с доверенным сертификатом: разместите содержимое `dist` на статическом HTTPS-хостинге или настройте доверенный HTTPS для разработки. Обычный Network URL Vite вида `http://192.168…` для микрофона не подходит. На компьютере разрешён `http://localhost`. При отказе разрешите микрофон в настройках сайта Chrome/Safari. Алгоритм проверяется на синтетических сигналах, но работа на реальной акустике и конкретном телефоне требует ручной проверки: играйте одну струну и приглушайте остальные. Допуск настройки — 40 центов, устойчивость — минимум 220 мс. Тесты: `node --test src/pitch.test.mjs`.

Текущий диапазон: гитара в стандартном строе, от Ми открытой 6-й струны до Соль на 3-м ладу 1-й струны. Только натуральные ноты, 17 разных высот; выбор октав убран. Звучание E2–G4, гитарная запись E3–G5. Шпаргалка и прогресс показывают позиции на струнах в пределах ладов 0–3. Статистика узнавания прежних позиций сохраняется; старые рекорды октав остаются в сохранении, но для нового диапазона используется отдельный рекорд.

Мобильный тренажёр чтения нот: React, TypeScript (strict), Vite.

Режимы: «Узнай ноту» (название), «Нота → гриф» (нажать струну и лад), «Гриф → нота» (выбрать одну из четырёх нот на стане). Гриф показывает струны 1–6 сверху вниз и лады 0–3; 0 означает открытую струну. В заданиях только натуральные ноты, но нажать можно любую позицию на грифе. Для новых режимов требуется точная высота, а не только название. Смена режима возвращает на старт тренировки; ответы, статистика, скорость и рекорды сохраняются отдельно в `nota-progress`, `nota-progress-to-fret`, `nota-progress-to-staff`. Сброс действует только на выбранный режим. Таймер остаётся скрытым во время задания.

## Запуск

```sh
npm install
npm run dev
```

В PowerShell с ограничением запуска скриптов используйте `npm.cmd` вместо `npm`.
Чтобы открыть на телефоне в той же Wi-Fi сети, используйте Network URL, который выводит Vite. При необходимости разрешите Node.js доступ к частной сети в брандмауэре Windows.

```sh
npm run build
npm run preview
```

Первая версия: 10 заданий, До–Си первой октавы, скрипичный ключ, подсказки, синтез звука через Web Audio и сохранение статистики в localStorage. Ошибки увеличивают вероятность повторения ноты; подряд одна нота не повторяется. Точность включает ответы с подсказкой. Звук соответствует обычной записи первой октавы, режим гитарной транспозиции пока не реализован.

Следующие этапы: отдельное упражнение на буквенные обозначения, ноты на грифе, связь грифа с нотным станом. Микрофон — после проверки основных режимов.

Карта знаний показывает общую самостоятельную точность по каждой ноте и последние 10 самостоятельных ответов. После пяти попыток статус определяется по последним ответам: от 80% — «Помню хорошо», от 50% — «Закрепляю», ниже — «Стоит повторить». Ответы после открытия подсказки (даже если её скрыли) учитываются отдельно. Общая точность тренировки по-прежнему включает подсказки. Старые общие показатели сохраняются; подробная статистика собирается с обновления.

Проверка расчётов статистики (Node.js 24): `node --test src/progress.test.mjs`.

Кнопки ответов перемешиваются для каждого задания, включая начало новой тренировки. При первом посещении появляется выбор занятия со звуком или без него; выбор и громкость сохраняются в `nota-audio`. Прогресс свёрнут в раскрывающийся блок: полосы показывают точность последних 10 самостоятельных ответов после минимум пяти попыток; до этого отображается «Мало данных».

Доступны три диапазона: первая октава, первая + До–Ре второй, две полные октавы (До первой — Си второй). Выбор сохраняется в `nota-range`. Смена диапазона начинает новую тренировку, сохраняя уже записанные ответы. Рекомендация расширения появляется, когда все ноты предыдущего этапа имеют статус «Помню хорошо»; блокировок нет. Ответы определяют название ноты независимо от октавы, а статистика хранится отдельно для каждой высоты. Старые данные семи нот автоматически дополняются пустой статистикой второй октавы. Шпаргалка и карта знаний показывают выбранный диапазон.

Все тесты: `node --test src/progress.test.mjs src/training.test.mjs`.

Таймер запускается кнопкой «Начать тренировку» и измеряет время от показа каждой ноты до ответа. Время разбора ошибок не входит в сумму. Открытие выбора звука и скрытие вкладки приостанавливают отсчёт и исключают этот ответ из рекордов и средней скорости ноты. Итоги показывают сумму и среднее время всех ответов; рекорд диапазона записывается только за 10 верных ответов без подсказок и прерываний. Карта знаний показывает среднее последних 10 верных самостоятельных ответов для каждой ноты. Сброс прогресса удаляет и рекорды. Старые сохранения автоматически получают пустую статистику времени.

Тесты таймера: `node --test src/timing.test.mjs`.
